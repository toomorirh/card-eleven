## 10. カードデザイン(レアリティ別)

| レア | 枠 | 演出 |
|---|---|---|
| N  | 鉄色フラット枠 | なし |
| R  | シルバーメタリック枠+1px銀ライン | 斜め光沢が約5.5秒周期で往復 |
| SR | 金二重枠+金発光 | 虹ホログラム背景(約5秒揺らぎ)+キラ流光+✦粒子2つ明滅 |
| L  | 虹色パレットサイクル枠(6コマ) | 強化ホロ+キラ流光+✦粒子3つ |

- SFCスキン下では SR/L の発光は「枠色の点滅(パレットアニメ風)」で表現。

### 10.1 カードレイアウト / ステータス表示(カード共通)
- カードサイズ **116×190px(mini 96×166px)**。一覧グリッド(`.grid`)は最大520px幅で**横4枚**まで。
- 上部: **ポジション(細分sub)バッジ**(左)。
- 中段(`.radar`): **6ステの六角レーダーを背景**に広げ、中央にスプライトを重ねる(`radarSVG`)。
  - 頂点順(時計回り・上から): OF(攻) / DF(守) / PO(力) / TE(技) / SP(速) / ST(持)。グリッドは3重六角、値ポリゴンは `値/20`。
  - 各頂点に略称+数値(`.rlab`)。**値が20(最大値)の数字は金色+発光(`.mx`)** で強調し、選手の長所を一目で示す。
  - レーダー塗り色はレア度連動(N/R=シアン、SR=金、L=ピンク)。mini では頂点ラベルを非表示にしポリゴン形状のみ表示。
- 下部(`.cinfo`): **選手名 → OVR+レア度 → プレースタイル → スキル名** を縦に配置(いずれも1行・ellipsis)。
- 略称 `STAT_SHORT`(OF/DF/PO/TE/SP/ST)。漢字ラベル(攻/守/…)は試合実況の `STAT_LABEL` で引き続き使用。

### 10.2 カード背景画像(レア/パラレル別)
カード枠に**イラスト背景**を敷いて洗練させる。単一HTMLを維持するため画像はビルド時に埋め込む。
- **アセット**: `src/assets/carddesign/ce_bg_<tier>.png`。tier=`emo`/`sig`/各パラレル(`danger`/`turbulence`/`obsidian`)等。`build.py` の `_cardbg_block` が **58:95 にオートクロップ→JPEG化**して `window.CARD_BG`(tier→data URI)へ注入。タイトル用は `ce_toppage_title.png`→`window.TOP_BG`(白 #f8f9f6 でフラット化)。
- **適用**: `applyCardBackgrounds`(boot時)が `CARD_BG_SEL`(tier→CSSセレクタ。パラレルは `.card.l.sig.par-<id>` のフル詳細度)ごとに背景を注入し、**スクリム(暗幕)CSSを弱め**て背景イラストが発光に飲まれないようにする。`--top-bg` も設定。
- **カード比率**: 116×190(=58:95)。拡大表示・キャプチャを見据え縦横比を固定。

### 10.3 ヘルプ(秘書ドロワー)と秘書ダイアログ
画面解説とイベント通知を、常設UIを増やさず**秘書キャラの吹き出し**で提供する。
- **ヘルプドロワー**: 各画面右端に小さな「HELP」タブ(`helpTab`)。タップで右から `helpDrawer` がスライドイン(`initHelpDrawer`)、秘書がその画面を解説。**位置は全画面共通で高さ56%**(サブメニューの有無で段差が出ないよう固定)。解説文は `HELP`(画面キー→文言)。隠れドロワーの `translateX(105%)` が横スクロールを起こさないよう `body{overflow-x:hidden}`。
- **秘書イベントダイアログ**: キャリアのイベント/操作結果を**画面中段のモーダル**(`.sec-dialog`)で提示し、確認してから進む。`SEC_EVENT_MSG`(key→文言)＋`secDialog(msg)`(Promise)／`secDialogSeq(keys)`。
  - **即時系**(練習で統率OVRアップ／カップエントリー完了／契約延長)は inline で `secDialog` を呼ぶ。
  - **試合結果系**(レッド欠場・成長爆発・不屈など)は `secMsgs[]` に集約し、結果ボタンから順に表示。
- **テスト配慮**: `document.addEventListener` が無いモックDOMでは `initHelpDrawer` をガード(統合テストのクラッシュ回避)。
