## 8. レジェンドパック(希少エンドコンテンツ)

- **入手**: 試合後の確率ドロップのみ(勝利18% / 引分8% / 敗北4%)。コイン購入・通常ガチャ不可。
- **中身**: 1枚。LEGEND 25% / SR 55% / R 20%。
- **目安**: 勝ち continuing で約7〜8試合に1パック、4パックに1枚LEGEND ≒ レジェンド1枚あたり約30勝。
- カードデザイン: 虹色パレットサイクル枠 + 強化ホロ + ✦3粒。

## 9. アセット仕様(スプライト)

- 頭部アトラス: 32種、セル `HCW×HCH = 100×96`、8列×4行。合成時の頭サイズ `HH=54`(描画高)。
- ボディアトラス: 16種 = ポジション4(`POSCOL={FW:0,MF:1,DF:2,GK:3}`)× ポーズ/バリエーション4、セル `BCW×BCH = 132×118`、4列×4行。**シグネチャーと等身を揃えた高い体型**(旧 BCH=88 から更新)。
- 合成: ボディを下に描画し、`BODY_ANCHOR[bodyIndex]`(首位置)に頭部を重ねる。等身はシグネチャー(全身1枚絵)に近い約2.5〜3頭身。
- **ボディatlasの作り方**: Gemini等で「頭なし・透過・キット中立の全身ボディ」をポジション別シート(`src/assets/bodies/body_{fw,mf,df,gk}.png`, 各4体・間隔を空ける)で用意 → `tools/build_body_atlas.py` で4×4 atlasへ正規化配置＋首アンカー(`BODY_ANCHOR`)自動算出＋WebP base64出力 → `data.js` の `BODY_IMG`/`BODY_ANCHOR`(必要なら `BCH`/`HH`)を差し替え。
- (代替) 汎用も全身1枚絵プールで描画する方式(B)が `GEN_IMG`/`tools/slice_bodies.py` として併存(現在はプール空=合成方式)。
- 縁処理: ソフトアルファ + 背景色除染 + 1px濃紺アウトライン + 孤立/グリッド片除去 + LANCZOS縮小 + WebP(品質88)。表示は `image-rendering:auto`。
- カードごとに `look.headIdx`(0-31)× `look.bodyVar`(0-3)で外見決定。保存される。

## 9.9 デザインシステム(洗練レトロ / refined retro)

**方向性**: ピクセルフォント(`DotGothic16`)・ドット絵選手・金(`--gold #e8c25a`)×ナイト(`--night #0c1626`)の魂を残しつつ、旧SFCスキンのハードな要素(白RPG枠3px・完全角ゼロ・強いスキャンライン・硬いピクセルベベル)を緩和した「プレミアムな懐かしさ」。**全コンポーネントをこの基準に統一**。

- **CSS2層**: `base.css`(構造・レイアウト)を `sfc-skin.css`(後勝ちの視覚スキン)が上書き。デザインの基準値は sfc-skin.css の先頭ブロックに集約。
- **角丸**: `*{border-radius:5px!important}`(全体に微かな角丸)。円形要素(close-btn/ボール/リング/円/監督肖像)のみ `border-radius:50%!important` で維持。
- **パネル枠**: 旧・白RPG枠 → **スチール枠 2px `#3a5680` + 柔らかい陰影**(`inset 0 1px 0 rgba(255,255,255,.06)` の上ハイライト + `0 3px 10px rgba(0,0,0,.45)` のドロップ)。対象=`.feed,.sheet,.score,.league-card,.subrow,.toast,.fieldview,.pitch` と新パネル群。
- **ボタン**: 金 = 縦グラデ+柔ベベル(`inset 0 1px 0 #fff4cc, inset 0 -2px 0 #c9a238, 0 2px 0 #8a6f28`)、`:active` で1px沈む。ghost = スチール(`#25395a→#1a2942`)。
- **背景**: 上方ビネット + 極薄チェッカー。**スキャンラインは `rgba(4,8,16,.06)`** まで低減(余韻程度)。
- **見出し**: `.banner`/`h1` は硬い3pxオフセット影 → 2px + 淡い金グロー。
- **モーダル**: 中央寄せ(§UI整備)+ スチール枠 + 微角丸。
