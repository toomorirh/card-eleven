## 4. プレースタイル(タイプ)

全選手がポジション別に複数種(FW6/MF6/DF5/GK3=計20種)のタイプを持つ。タイプは「活動場所・積極性・ポゼッション・イベント選出率(=どの崩し方を好むか)・オフザボールの動き・カットイン語・系統色・トレードマーク(§6.5.3)」に影響する。

### 4.1 パラメータ定義
| キー | 意味 |
|---|---|
| `adv` | 前後オフセット(+で前線寄り) |
| `wide` | サイドへの張り出し |
| `roam` | 徘徊量(ランダム移動の大きさ) |
| `chase` | ボールへの吸着度 |
| `poss` | 支配率への貢献倍率 |
| `atk/tgt/pas/defSel` | 各イベントの選出重み倍率 |
| `run` | オフザボールの飛び出し頻度 |
| `wideSel` | サイドアタック起点になれる適性 |

### 4.2 タイプ一覧
**FW**: ストライカー(striker, 最前線/シュート関与大/poss低) / ポストプレイヤー(post, 低めで収める/tgt最大/poss高) / ドリブラー(dribbler, サイドに流れ大きく動く) / シャドー(shadow, ライン間で飛び出し) / **ゴールハンター(poacher, ボックス専業/run最大/持ち込み最小)** / **偽9番(false9, 下りて捌く/poss高・pas持ち)**
**MF**: ゲームメーカー(maker, 中央低め/poss最高) / ボックストゥボックス(b2b, 縦に往復/run最大) / ウインガー(winger, タッチライン際) / アンカー(anchor, DF前/守備選出) / **レジスタ(regista, 最終ライン近くで散らす/pas最高・drive最小)** / **デストロイヤー(destroyer, 球際/defSel高・poss低)**
**DF**: ストッパー(stopper, 前に出て潰す/defSel1.5) / カバー(cover, 最後尾) / 攻撃的SB(sb, 外を上下動) / **リベロ(libero, 持ち上がって組み立て/poss・pas高)** / **ウイングバック(wingback, 大外を制圧/wide・run最大)**
**GK**: シュートストッパー(liner, ライン上) / スイーパー(sweeper, 高い位置/poss1.4) / コマンダー(commander, 中間)

一部シグネチャーは新タイプへ寄せてある(ブスケツ=regista / ヴィエラ=destroyer / ベルカンプ=false9 / R.カルロス・カフー=wingback)。

> 実数値は実装の `TYPES` 定数を参照(本SPECでは設計意図を記載。数値変更時は両方更新)。
> QR共有はタイプindexを **v4(0xC4)で3bit**(最大8種/ポジション)に拡張。v3(0xC3)/v2(0xC2)は2bitとして読込互換。

### 4.3 年齢 `age`(カードの実パラメータ)
基礎ステとは**独立**の年齢(16〜38)。パワーそのものではなく「伸びしろと動き方の質」を決める軸。`AGE_PHASES`(`ageOf`/`agePhase`/`effAge`)がフェーズ→各レバー倍率を返す(全盛期=1.0が基準)。
- **全モードで効く3レバー**(直交・`eff`には入れない): ① **関与** `ageInv`(選出重み=`pick*`/`CHANNELS.pickOrigin`/`offBallRun`)、② **スタミナ** `ageDrain`(`fatigue` の消費項)、③ **勝負強さ** `ageCompose`(`resolveDuel`/`resolveShot` の各選手スコア)。若手=走り回るが息切れ・勝負は荒い / ベテラン=省エネで出番少だが成功率高。
- **フェーズ**: 🌱若手(〜21)/🌿成長期(22-25)/⭐全盛期(26-29)/🎖ベテラン(30-33)/🔥老雄(34〜)。各に `growth/condVol/decline`(育成用=Phase2)も定義。
- **付与**: 通常カード=`rollAge`(17〜34・ピーク24-26)。シグネ/エモは**固定年齢**(データ定義)=意図的な選択軸(例 ヤマル17🌱/メッシ37🎖/ブッフォン41🔥)。**エモは"瞬間"の年齢**(CR7エモ=19🌱 ↔ 現代シグネは30代)で同選手の差分。
- **移行/QR**: `loadGame` が欠落カードへ `defaultAge` 付与(版非依存)。QR共有は **v5(0xC5)で age 5bit**(age-16)同梱。v4以前は非同梱→取り込みは `AGE_DEF`(27=全盛期)扱い。
- **育成での加齢/成長/コンディション**(Phase2・実装済み): §7.10.1「選手のシーズン内成長」を参照。実効年齢は育成中シーズンごとに+1(`effAge` の `ageBonus`=`cr.season`。カード本体は不変=ローグライク)。

## 5. スキル

`fx` のキーが試合エンジンで参照される効果フラグ。

### 5.1 効果キー
`save`(GKセーブ) `duelD`(守備マッチアップ) `duelSpd/duelPow/duelTec`(各勝負) `shoot`(シュート) `mid`(個人支配率) `teamChance`(チーム創出) `teamDef`(チーム守備) `iron`(消耗なし) `clutch`(70分以降) `losing`(ビハインド時) `miracle`(失点無効・LEGEND)

### 5.2 通常スキル(R=1個 / SR=1個強力。N=なし)
- GK: R[セービング, 飛び出し] / SR[神の手, 守護神]
- DF: R[ハードプレス, 鉄人] / SR[完全密着, 統率]
- MF: R[パスワーク, ダイナモ] / SR[司令塔, ファンタジスタ]
- FW: R[決定力, スピードスター] / SR[怪物, 勝負師]

### 5.3 レジェンド専用スキル(`LSKILLS`、LEGENDのみ)
- GK: **奇跡の手**(1試合1回 失点無効化 + MIRACLE!!カットイン) / 絶対領域(save 1.7)
- DF: 鉄壁の壁(duelD 1.7) / 守護王(teamDef 1.3)
- MF: 王の視野(teamChance 1.4) / マエストロ(mid 1.6 + duelTec 1.35)
- FW: 伝説の一撃(shoot 1.5) / 覇王(duelSpd/Pow/Tec 各1.3)
